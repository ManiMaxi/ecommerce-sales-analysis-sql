#### **E-commerce Sales \& Customer Analysis Using SQL**

###### 

###### **Project Overview** 

&#x09;This project analyzes e-commerce sales, customer behavior, product performance, and order trends using MySQL. The goal is to explore business data, identify meaningful patterns, and answer business questions using SQL.



###### **Dataset** 

The project contains five related tables:

* customers: Customer details, locations, and signup dates.
* orders: Order dates, statuses, customers, and payment methods.
* order\_items: Products purchased, quantities, prices, and discounts.
* products: Product names, categories, cost prices, and selling prices.
* payments: Payment dates, methods, and payment statuses.



###### **Data Cleaning** 

The raw dataset was reviewed for data-quality issues, including:

* Duplicate records
* NULL, N/A, and blank values
* Inconsistent text casing
* Inconsistent state names and state codes
* Different date formats
* Invalid numerical values



SQL was used to investigate and handle relevant data-quality issues before analysis.



###### **Exploratory Analysis** 

* Dataset size and table structure
* Customer and order distributions
* Product categories and numerical values
* Payment methods and statuses
* Date ranges and data relationships
* Data-quality and integrity checks 



###### **Business Analysis** 

The project answers 25 business questions covering:

* Sales and revenue
* Customer behavior
* Product and category performance
* Payment methods
* City-level analysis
* Monthly revenue trends
* Month-over-month growth
* Running totals
* Product ranking
* Customer revenue contribution



###### **SQL Skills Used** 

* Joins
* Aggregate Functions
* GROUP BY and ORDER BY
* CASE WHEN
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* ROW\_NUMBER() and RANK()
